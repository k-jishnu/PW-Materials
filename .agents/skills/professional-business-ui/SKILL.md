# Professional Business UI Skill

When working on frontend interfaces:

1. Inspect the existing application and understand its framework, components, routes, and styling before editing.
2. Prefer a clean, restrained business application aesthetic over generic AI-generated dashboard designs.
3. Use the PW Materials design tokens:
   - Primary: #2563EB
   - Primary hover: #1D4ED8
   - Text: #172B4D
   - Secondary text: #64748B
   - Background: #F6F8FB
   - Surface: #FFFFFF
   - Border: #E2E8F0
   - Success: #15803D
   - Warning: #B45309
   - Error: #B91C1C
4. Use consistent typography, spacing, button sizes, borders, form controls, and iconography.
5. Remove redundant content and decorative UI elements only after confirming they are not needed for functionality.
6. Use semantic HTML, accessible labels, visible focus indicators, keyboard-friendly interactions, and appropriate color contrast.
7. Design desktop layouts first where appropriate, but explicitly verify tablet and mobile behavior.
8. Reuse existing components and dependencies before introducing new ones.
9. Never replace working business logic, real data, or API integrations with mock implementations during a visual redesign.
10. Test important interactions and inspect the rendered application whenever browser tools are available.
11. Run relevant build, lint, and type-check commands after changes.
12. Report what was tested and clearly identify anything that could not be verified.

Prioritize functional correctness, clarity, accessibility, and consistency over decorative effects.
